> 与 stock 共用阿里云 120 · Docker PG（`stock-pg`）

| 项 | 值 |

| 路径 | `/opt/flowledger` |

## 2. 安全组

- 放行：`8900`（Web，已反代 API）、SSH；可选 `9011`（API 直连）
- **不放行**：`5432`
- 建议：业务端口收紧来源 IP（个人财务无鉴权）

## 3. 日常命令

```bash
# 重新部署（跳过库）
SKIP_DB=1 bash scripts/deploy/deploy-aliyun.sh

# 强制重导本机 dump
FORCE_DB_RESTORE=1 DUMP_FILE=/tmp/flowledger-deploy/flowledger.sql \
  bash scripts/deploy/deploy-aliyun.sh

# Mac 推库
bash scripts/deploy/db-tunnel.sh -d
bash scripts/deploy/push-db-to-cloud.sh

# 云端日志
ssh root@120.25.145.131 'pm2 logs flowledger-api --lines 80'
ssh root@120.25.145.131 'tail -100 /opt/flowledger/logs/*-cron.log'
ssh root@120.25.145.131 'DEPLOY_ENV=cloud bash /opt/flowledger/scripts/verify.sh'
```

## 4. 同步通道（检查要点）

| 通道 | 机制 | 调度 | 备注 |
|------|------|------|------|
| Mac → 云 `flowledger` | `db-tunnel.sh`(:15433) + `push-db-to-cloud.sh` | 手动（尚无 LaunchAgent） | 财务流水真源在 Mac |
| Mac → 云 `invest` | stock 隧道 :15432 + stock 推库 | stock LaunchAgent | FlowLedger 只消费 |
| 同机 invest → holdings | `sync-invest.sh` / `POST …/sync-from-invest` | cron `*/30` | PM2 须 `--update-env`，否则旧 `INVEST_DATABASE_URL` 会盖掉 `.env` |

排障：先 `curl -sS -w '%{http_code}' -X POST http://127.0.0.1:9011/api/holdings/sync-from-invest`，再看 `pm2 env flowledger-api` 与 `/opt/stock/deploy/.env.pg` 是否一致。

## 5. 纪律

1. **禁止**再起 `flowledger-pg` 占用端口。
2. 对 `stock-pg` 只增库、不无备份重建。
3. invest 外采写库只在 Mac；云端仅 `sync-invest` 读同机 invest。
4. 密码仅 `.env` / `deploy/.env.pg` / 本机 `.env.cloud.local`，不入库。
5. stock 改密后：即使 `SKIP_DB=1` 部署也会刷新 `INVEST_DATABASE_URL`；改完需 `pm2 restart flowledger-api --update-env && pm2 save`。
